# Portfólio profissional

Portfólio profissional de **Natam dos Santos**, estudante de Análise e Desenvolvimento de Sistemas, desenvolvido com HTML5 e CSS3 e publicado no GitHub Pages.

## Sobre o projeto

Este portfólio foi criado como atividade da disciplina **Design Profissional** (Projeto 2: publicação do portfólio profissional no GitHub), ministrada pelo Prof. Vinicius Alves Rodrigues.

O site reúne a apresentação profissional, a formação, as competências, os projetos desenvolvidos, o currículo e os canais de contato de Natam dos Santos.

## Objetivos

- Apresentar minha trajetória e minhas competências de forma clara e verdadeira
- Mostrar os projetos que desenvolvi durante a formação
- Praticar HTML semântico, CSS responsivo e acessibilidade
- Aprender a organizar e publicar um projeto com Git e GitHub (commits, branch, pull request e GitHub Pages)

## Tecnologias utilizadas

- HTML5
- CSS3 (Flexbox e Grid)
- Git e GitHub
- GitHub Pages (publicação)
- VS Code (edição do código)

O projeto não usa frameworks, bibliotecas externas nem JavaScript.

O site é dividido nas seguintes seções: Apresentação, Sobre mim, Formação, Competências (técnicas e comportamentais), Projetos, Currículo, Contato e Rodapé.

## Projetos apresentados

- **LyricAI:** site que cria músicas automaticamente. A pessoa escolhe o gênero, digita palavras-chave e a IA gera o resultado. Criado com o Claude a partir de prompts escritos por mim, na aula de prompt de IA.
- **Lista de tarefas:** projeto em grupo feito em Python. Fui responsável pelo design das telas de login e principal, com o Antigravity como ferramenta de apoio.
- **Página inspirada no iFood:** página com cartões de produtos, preços e botão de adicionar, criada na aula de prompt para praticar o desenvolvimento web com ajuda de IA.
- **Cartão de visitas digital:** página criada sozinho para praticar HTML e CSS.

1. Baixe ou clone o repositório:
